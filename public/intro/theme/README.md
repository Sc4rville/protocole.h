# Theme song

Drop the theme song here as `theme-song.ogg` (preferred) and/or `theme-song.mp3`.

`intro.js` looks for it when the page loads and fades it in (4 s) at the start of the
briefing. If no file is present, a room-tone placeholder plays instead and the briefing
shows a small note. The prologue never plays music: SFX and synthesized tension only.

Suggested export: 48 kHz, OGG Vorbis q5, loop-safe or with a long tail.
